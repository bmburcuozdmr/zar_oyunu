# 🎲 Zar Yolu – Stratejik Kutu Oyunu

Flutter ve Dart kullanılarak geliştirilen modern, iki oyunculu strateji ve yarış oyunu.

## 📌 Proje Hakkında
Zar Yolu, zar şansını stratejik kararlarla birleştiren bir mobil oyundur. Oyuncular piyonlarını bitiş çizgisine ulaştırmaya çalışırken; kestirme köprüleri, artı/eksi kareleri ve kontrol noktası skorlarını yönetir.

## 🛠️ Kullanılan Teknolojiler
- **Flutter & Dart**
- **Durum Yönetimi (State Management):** Aşama aşama entegre edilecek
- **Dokümantasyon:** Markdown tabanlı teknik raporlama
